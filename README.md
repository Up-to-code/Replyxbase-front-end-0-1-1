## Technology

Next.js, React, TypeScript.

## Get started

```sh
git clone https://github.com/Up-to-code/Replyxbase-front-end-0-1-1.git
cd Replyxbase-front-end-0-1-1
```

Requires Node.js and pnpm.

```sh
pnpm install
pnpm dev
```

## Available commands

| Command | Purpose |
| --- | --- |
| `pnpm dev` | Development server |
| `pnpm start` | Start the configured application |
| `pnpm build` | Build the project |
| `pnpm lint` | Check lint rules |
